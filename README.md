# Calculadora de Reservatório

Uma calculadora web responsiva para estimar:

- Volume total em litros e metros cúbicos
- Volume preenchido
- Percentual livre
- Autonomia em dias com base no consumo diário

## Formatos suportados

- Reservatório retangular
- Reservatório cilíndrico

Abra o arquivo `index.html` em um navegador para utilizar a calculadora.
